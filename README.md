# Neon Pursuit

Régulateurs contre coureurs, en multijoueur, dans une ville cyberpunk de nuit (vue isométrique).

## Télécharger

👉 **[Télécharger la dernière version (Windows)](https://github.com/Popp-Ranger/neon-pursuit-jeu/releases/latest)** :
dans la page qui s'ouvre, clique sur le fichier `NeonPursuit-….zip` (rubrique *Assets*).

1. Décompresse tout le dossier (garde `NeonPursuit.exe` et `NeonPursuit.pck` ensemble).
2. Lance `NeonPursuit.exe`.

Windows peut afficher « Windows a protégé votre ordinateur » : le jeu n'est pas signé numériquement (petit jeu fait
maison). Clique sur **Informations complémentaires**, puis **Exécuter quand même**.

## Jouer ensemble

- Un joueur **héberge** la partie, les autres la **rejoignent** avec son adresse IP.
- Par Internet, le plus simple : un réseau virtuel gratuit (Radmin VPN, ZeroTier ou Tailscale). Sinon, l'hôte ouvre le
  port **24600 en UDP** sur sa box.
- Le fichier `LISEZMOI.txt` du jeu détaille tout (commandes, règles).

## But du jeu

- **Coureurs** : rejoindre la planque avant la fin du chrono sans se faire arrêter.
- **Régulateurs** : taser un coureur, le menotter, le ramener au QG de la régulation.
